# Golden fixture contract

Fixtures are produced by the C oracle (`oracle/`) and consumed by Go (`go test -tags golden`) and
TypeScript (vitest) tests. Inputs live in `fixtures/scenarios/` (committed); outputs in
`fixtures/generated/` (gitignored, regenerated by `make fixtures`, hashes in `fixtures/MANIFEST.sha256`).
Tests locate outputs via env `Q2_FIXTURES` (default `<repo>/fixtures/generated`) and game data via
`Q2_BASEDIR` (default `<repo>/assets/demo`, containing `baseq2/pak0.pak`). Tests **skip** (not fail)
when fixtures or data are absent.

## Encoding rules
- JSON Lines (`.jsonl`): one JSON object per line. Plain JSON (`.json`) for single records.
- C `float` values are printed with `%.9g` (round-trips float32 exactly). Consumers parse as float64 and
  narrow: Go `float32(v)`, TS `Math.fround(v)`. Comparison is exact (bitwise) unless `spec/tolerances.json`
  says otherwise.
- C `double` values: `%.17g`. Integers: decimal. Byte buffers: lowercase hex string.
- Vectors: arrays of 3 numbers. `short[3]`: arrays of 3 integers.
- Maps are referenced by name (`demo1`), loaded from `maps/<name>.bsp` inside the pak.

## core/bsp/<map>.json  (oracle_core bsp)
```
{ "map":"demo1", "checksum": <int, CM_LoadMap checksum as unsigned 32-bit>,
  "numclusters":N, "numareas":N, "numleafs":N, "numnodes":N, "numplanes":N, "numbrushes":N,
  "numbrushsides":N, "numleafbrushes":N, "numtexinfo":N, "numareaportals":N, "numcmodels":N,
  "entitystring_sha256":"...",
  "cmodels":[{"mins":[..],"maxs":[..],"origin":[..],"headnode":N}],
  "pvs":["<hex of CM_ClusterPVS row, (numclusters+7)>>3 bytes>", ...],   // per cluster
  "phs":["<hex>", ...],
  "leafs":[{"contents":N,"cluster":N,"area":N}]                              // per leaf
}
```

## core/trace/<map>.jsonl  (oracle_core trace)
One line per query:
```
{"q":{"kind":"box"|"transformed"|"point"|"pointt"|"leaf",
      "start":[..],"end":[..],"mins":[..],"maxs":[..],"headnode":N,"mask":N,
      "origin":[..],"angles":[..], "p":[..]},
 "r":{"allsolid":0|1,"startsolid":0|1,"fraction":f,"endpos":[..],
      "plane":{"normal":[..],"dist":f,"type":N,"signbits":N},
      "surface":{"name":"...","flags":N,"value":N},"contents":N}}
```
`box`: CM_BoxTrace(start,end,mins,maxs,headnode,mask). `transformed`: CM_TransformedBoxTrace(..., origin, angles).
`point`: `r = {"contents": CM_PointContents(p, headnode)}`. `pointt`: CM_TransformedPointContents(p,headnode,origin,angles).
`leaf`: `r = {"leaf": CM_PointLeafnum(p)}`. When the trace hits nothing, `surface` is the null surface (`name:""`).

## core/pmove/<scenario>.jsonl  (oracle_core pmove)
First line: `{"header":{"map":"demo1","airaccelerate":f}}`. Then one line per usercmd:
```
{"cmd":{"msec":N,"buttons":N,"angles":[s,s,s],"forwardmove":N,"sidemove":N,"upmove":N,"impulse":N,"lightlevel":N},
 "in":{ pmove_state (only on the first step and whenever the scenario resets state) },
 "out":{"s":{"pm_type":N,"origin":[s,s,s],"velocity":[s,s,s],"pm_flags":N,"pm_time":N,"gravity":N,"delta_angles":[s,s,s]},
        "viewangles":[..],"viewheight":f,"mins":[..],"maxs":[..],"groundentity":0|1,
        "watertype":N,"waterlevel":N,"numtouch":N}}
```
State is carried from step to step (`out.s` becomes the next input) unless an `in` is given. Trace callback:
`CM_BoxTrace(start, end, mins, maxs, 0, MASK_PLAYERSOLID)` (world only, like CL_PMTrace without entities);
pointcontents: `CM_PointContents(p, 0)`. `snapinitial` is false.

## core/msg/<kind>.jsonl  (oracle_core msg)
- `entity.jsonl`: `{"from":ES,"to":ES,"force":0|1,"newentity":0|1,"bytes":"<hex of MSG_WriteDeltaEntity>"}`
  where ES = `{"number","origin","angles","old_origin","modelindex","modelindex2","modelindex3","modelindex4","frame","skinnum","effects","renderfx","solid","sound","event"}`.
- `usercmd.jsonl`: `{"from":UC,"to":UC,"bytes":"<hex of MSG_WriteDeltaUsercmd>"}` (UC as in pmove `cmd`).
- `player.jsonl`: `{"from":PS|null,"to":PS,"bytes":"<hex>"}` using the body of SV_WritePlayerstateToClient
  (PS = pmove state + viewangles, viewoffset, kick_angles, gunangles, gunoffset, gunindex, gunframe, blend[4], fov, rdflags, stats[32]).
- `scalar.jsonl`: `{"op":"coord"|"angle"|"angle16"|"pos"|"dir"|"float"|"string"|"long"|"short"|"char"|"byte","v":<value>,"bytes":"<hex>"}`.
- `crc.jsonl`: `{"base":"<hex>","sequence":N,"crc":N}` for COM_BlockSequenceCRCByte; `{"block":"<hex>","crc16":N}` for CRC_Block.
- `md4.jsonl`: `{"block":"<hex>","checksum":N}` for Com_BlockChecksum (unsigned 32-bit).

## core/rand.json  (oracle_core rand)
`{"seed":1,"values":[... first 100000 values of rand() after srand(1) ...]}` plus `{"seed":12345,...}` in `rand-12345.json`.

## core/pak/<pak>.json  (oracle_core pak)
`{"files":[{"name":"...","filepos":N,"filelen":N,"sha256":"..."}]}` in directory order.

## game/<scenario>.jsonl  (oracle_game / oracle_game_ctf)
Scenario input (`fixtures/scenarios/game/<name>.json`):
```
{"map":"demo1","module":"baseq2"|"ctf","entstring_override":null|"...","seed":1,
 "cvars":{"skill":"1","deathmatch":"0","coop":"0","maxclients":"1",...},
 "clients":[{"userinfo":"\\name\\player\\skin\\male/grunt\\hand\\0\\fov\\90"}],
 "frames":600,
 "schedule":[{"frame":N,"client":0,"cmd":UC} | {"frame":N,"client":0,"command":"give all"} |
             {"frame":N,"client":0,"random_walk":{"seed":7,"until":600}}]}
```
Output: first line `{"header":{...scenario echo..., "edict_size":N}}`, then one line per server frame:
```
{"frame":N,"level":{"framenum":N,"time":f,"killed_monsters":N,"total_monsters":N,"found_secrets":N,"total_secrets":N},
 "rand_calls":N,
 "edicts":[{"n":N,"classname":"...","s":ES,"solid":N,"svflags":N,"mins":[..],"maxs":[..],"health":N,
            "movetype":N,"flags":N,"nextthink":f,"velocity":[..],"avelocity":[..],"groundentity":N|-1,
            "enemy":N|-1,"owner":N|-1,"takedamage":N,"deadflag":N,"waterlevel":N,"spawnflags":N,
            "think":"<C function name or null>","aiflags":N|null,"currentmove":"<mmove name or null>"}],
 "clients":[{"ps":PS,"inventory":[256 ints],"health":N,"score":N,"weapon":"<classname>"|null}],
 "events":[{"t":"sound","ent":N,"channel":N,"sound":"<name>","volume":f,"attenuation":f,"timeofs":f} |
           {"t":"positioned_sound",...,"origin":[..]} |
           {"t":"configstring","index":N,"value":"..."} |
           {"t":"print","kind":"bprintf"|"cprintf"|"centerprintf"|"dprintf","ent":N|-1,"level":N,"text":"..."} |
           {"t":"multicast","origin":[..],"to":N,"bytes":"<hex>"} | {"t":"unicast","ent":N,"reliable":0|1,"bytes":"<hex>"} |
           {"t":"cmd","text":"..."}]}
```
Only `inuse` edicts are listed. Function names are resolved from the game module's symbol table (`dladdr`)
so fixtures name callbacks exactly as the Go registry does. `rand_calls` counts `rand()` calls made during the frame.
