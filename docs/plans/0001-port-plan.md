# Quake 2 → Go server + TypeScript/WebGL2 browser client + Next.js

## Context

`Quake-2/` holds the id Software Quake 2 **v3.19** GPL source (protocol 34, game API 3; ~174K lines of C across `qcommon/ server/ client/ ref_gl/ ref_soft/ game/ ctf/` + platform dirs). It is the **oracle**: never edited, only read and compiled into test harnesses. Goal: a complete, quality-assured port to a modern stack — a Go authoritative game server, a hand-ported TypeScript client rendering with WebGL2 in the browser, and a Next.js shell — with all game modes (single-player, coop, deathmatch, CTF).

No game data exists in the tree (no pak/bsp/md2/pcx). The engine cannot even start without `pics/colormap.pcx`. The freely redistributable **shareware demo** will be fetched by script; retail data is uploaded by the user.

Effective port surface ≈ 100K lines of C (qcommon 9K, server 6K, client 25K, ref_gl 10K, game 50K, CTF-unique ~8K) → ~110–130K lines of Go+TS plus tests/harness/shell. This is a multi-month program; the plan is phased so each phase ends in something demoable and oracle-gated.

## Decisions (locked with the user)

| Topic | Decision |
|---|---|
| Simulation | Authoritative **Go server** runs `qcommon` + `server` + `game` + `ctf`. Every session — including single-player — is a game instance on the server. |
| Client | **Hand-ported TypeScript**, WebGL2 renderer (port of `ref_gl/` only; `ref_soft/` dropped), AudioWorklet port of the mixer. Not Emscripten. |
| Transport | WebSocket binary frames; one WS message == one original UDP datagram **including the 10-byte netchan header** (ADR-0001). Lets a dumb UDP↔WS bridge connect the TS client to the real C dedicated server for differential testing. Transport abstraction for WebTransport later. |
| Assets | Users upload pak files; Go ingests them once. **BSP/MD2/SP2/WAV/CIN served verbatim** (already little-endian, typed-array friendly; the client needs every BSP lump for collision + PVS anyway); **PCX/WAL/TGA → PNG** + palette export; per-map manifest. GL-side work (lightmap atlas, polygon build, warp subdivision) stays in TS so the whole `ref_gl` port lives in one language and is oracle-testable. |
| Scope v1 | SP campaign, coop, deathmatch, and the `ctf/` mod. |
| UI | Hybrid: React (Next.js) for out-of-game shell (auth, pak upload, server browser, lobby, saves, options/binds; `menu.c`/`qmenu.c` become React with Q2 aesthetic). In-canvas faithful ports: HUD layout language, console, inventory, scoreboard/`svc_layout`, CTF menus, centerprint, loading plaque, cinematics. |
| Backend | Postgres + accounts (server-side saves per user), stdlib `net/http` mux, pgx + sqlc + goose, Docker Compose. |
| Quality | Every subsystem tested; golden fixtures generated by a natively compiled **C oracle harness** consumed by both Go and TS tests; differential testing against the real C dedicated server. `docs/PARITY.md` tracks every original file's disposition. |
| Tick | Keep the fixed **10 Hz** server frame (`FRAMETIME 0.1` is baked into 114 call sites); usercmds processed on arrival; client interpolates. No catch-up frames (C clamps realtime). |
| Numerics | C `float` → Go `float32` / TS `Math.fround`; expressions evaluated in C's promoted type (ADR-0003). glibc-exact `rand()` port in both languages (ADR-0002). `pmove`/`cmodel`/`msg` must be **bit-identical** across C/Go/TS. |
| Oracle build | **64-bit** with `-ffp-contract=off -fno-fast-math -fexcess-precision=standard -fcommon` + 3 tiny LP64 patches (`md4.c` `UINT4`→`unsigned int`, `sv_ents.c:509` `long`→`int`, `sv_world.c` `STRUCT_FROM_LINK` cast→`intptr_t`). **gcc-multilib is not required** (optional `-m32` cross-check later). |

## Environment

Go 1.22.2 (go.mod will declare `go 1.23` + `toolchain`; auto-downloads), Node 22, pnpm, gcc 13, make, docker + compose v5, unzip/7z, psql. Git repo initialized, **no commits yet**. All C sources are LF (no line-ending normalization needed).

Demo pak: `https://deponie.yamagi.org/quake2/idstuff/q2-314-demo-x86.exe` (~39 MB; plain zip → `Install/Data/baseq2/pak0.pak`, 47 MiB). Contains Unit 1 (`base1/2/3`) + a subset of monsters/weapons/sounds; no cinematics, no DM/CTF maps (verify with `q2tool pak ls` in Phase 0).

## Architecture

### Go server (`server/`)

Packages (one goroutine owns one instance; **no package-level mutable state**; immutable data — parsed BSP, `cmodel.Map`, item table, mmove tables, function registry — shared read-only, LRU by content hash):

| Package | Ports | Notes |
|---|---|---|
| `internal/qcommon/shared` | `game/q_shared.c/.h` | `Vec3 [3]float32`, EntityState, PlayerState, PmoveState, UserCmd, Trace, `COM_Parse`, `Info_*`, AngleVectors, `bytedirs` |
| `internal/qcommon/msg` | `common.c` MSG_* (`:281-870`), `sv_ents.c` playerstate delta | byte-exact: coords `int16(x*8)`, angle byte/short, `U_*`/`PS_*`/`CM_*` bits |
| `internal/qcommon/{cvar,cmd,crc,md4,crand}` | `cvar.c`, `cmd.c`, `crc.c`, `md4.c`, glibc `rand()` TYPE_3 | per-instance registries; `crand` verified against `oracle_core rand` |
| `internal/bsp` | `qfiles.h` IBSP 38, 19 lumps | shared by cmodel + ingest; bounds-checked, fuzzed |
| `internal/cmodel` | `cmodel.c` (1770) | immutable `*Map` + per-instance `PortalState`; `BoxTrace`, `TransformedBoxTrace`, PVS/PHS, areas; MD4 checksum → `CS_MAPCHECKSUM` |
| `internal/pmove` | `pmove.c` (1360) | float32; `AirAccelerate` field, no globals |
| `internal/sv` | `server/*.c` | `Server`, `Client`, `ClientFrame[16]`, area-node world (`sv_world.c`), handshake (`sv_user.c`), snapshots/delta (`sv_ents.c`), multicast/rate (`sv_send.c`), `game.Import` impl (`sv_game.c`), `SpawnServer` + configstring indexing (`sv_init.c`), map/save/load flows (`sv_ccmds.c`) |
| `internal/game` | `game/*.c` + `ctf/*.c` | **one package**; 3.19 base; CTF hunks inline at the `//ZOID` sites guarded by `ctf` cvar; monsters not spawned when `ctf` set; `ctf.go`, `ctf_menu.go` |
| `internal/save` | replaces `g_save.c` | versioned DTOs, JSON + zstd, `Slot{Server, Game, Levels map[map]LevelFile}` |
| `internal/host` | new | instance manager, per-instance goroutine loop, join tickets, idle reaping |
| `internal/net/transport` (+`ws`) | `net_chan.c` | `Conn{Recv,Send,Close}`; netchan header kept; optional raw UDP listener for C-client tests |
| `internal/assets` | `files.c` + format loaders | pak/md2/sp2/wal/pcx/tga/wav/cin parsers, ingest jobs, content-addressed blobstore, manifests |
| `internal/{api,auth,db,config}` | new | stdlib mux, argon2id sessions (cookie), one-time WS tickets, pgx/sqlc/goose, env config, slog, Prometheus |

Key design points:
- **Edicts**: `Game.Edicts []Edict` (len `maxentities`), stable `*Edict`, `Index` replaces pointer arithmetic; `G_Spawn` slot-reuse policy kept exactly (`g_utils.c:420`) so entity numbers match the oracle.
- **Function pointers** → comparable handles into a **named registry** (`ThinkFn{id}`, `UseFn`, `TouchFn`, `PainFn`, `DieFn`, `BlockedFn`, `AIFn`, `MonsterFn`, item fns) registered under the **C function name** (`RegisterThink("soldier_stand", (*Game).soldierStand)`). `mmove_t` tables are immutable package-level `*MMove` registered by name. Save writes names; a test asserts completeness/uniqueness.
- `G_Find(FOFS)` → typed string accessors; `ED_ParseField` → map keyed by the exact `fields[]` entries of `g_save.c:27-119` (incl. `F_ANGLEHACK`, `FFL_SPAWNTEMP`, `FFL_NOSPAWN`).
- All game globals (`level`, `game`, `st`, `meansOfDeath`, per-monster `sound_*`, `ctfgame`) → fields on `*Game`; game functions are methods on `*Game`.
- Item table: 3.19 `itemlist[]` + CTF items appended (stable indices in all modes); save stores classname.
- **Instance loop**: `select` on client inbox (execute `clc_*` immediately → `ClientThink`), control channel (API closures), 100 ms ticker (`Frame()`: CalcPings → GiveMsec → framenum++ → `RunFrame` → SendClientMessages → PrepWorldFrame; one `rand()` per frame as in `SV_Frame`).
- **Handshake**: `POST /games/{id}/join` → ticket; `GET /ws/v1/games/{id}?ticket=` → `getchallenge`/`connect` OOB packets kept (bridge compatibility), then `new → serverdata/configstrings/baselines → begin` verbatim. `svc_download` answered "not found"; assets come over HTTP. `CS_STATUSBAR` sent as one full string (client must accept up to 1536 bytes).
- **Save/load flows** verbatim from `sv_ccmds.c`/`sv_init.c`: autosave on level change, `SV_CheckForSavegame` 100-frame settle with `ss_loading`, coop `client_persistant_t` carried; Postgres `saves(user_id, slot, blob bytea, …)`.

## Porting conventions (`docs/PORTING.md`, summarized)

- One Go/TS file per C file, same base name; functions keep C names in idiomatic casing; doc comment `// C: qcommon/pmove.c:271 PM_StepSlideMove`.
- **No behavior changes**; deviations behind flags defaulting to original and logged in `PARITY.md` TODO-IMPROVE (exception: memory-safety fixes on network input, documented).
- Constants only from generated files; cvar names/defaults/flags copied exactly.
- Floats: `float32`/`fround` storage; `float*double-literal`, `sin/sqrt/fabs(float)` evaluated in double then narrowed (`float32(float64(a)*0.1)` / `Math.fround(a*0.1)`); `float*float` single (`Math.fround(a*b)` is exact); explicit conversions block FMA (`GOAMD64=v1`; arm64 nightly guard); shared fdlibm-based `qmath.Sin/Cos/Atan2` in both languages, `sqrt` native.
- Integers: `(int)f` → `int32(f)`/`Math.trunc`; `short` wrap via `Int16Array`/`int16()`; `char` signed.
- RNG: every `rand()` call site ported in the same order; `random()` = `rand()&0x7fff`; injected per instance; tests seed 1.
- Pointers → indices/handles; strings are byte strings at protocol level.
- `Com_Error(ERR_DROP)` → panic/recover at frame boundary (Go, per instance) / thrown `DropError` (TS).
- PR checklist: all C functions present or dispositioned; second-person side-by-side read for game logic files; RNG order; float rules; cvars; no new behavior; oracle fixture covers the file (or reason); no package-level mutable state; `go vet`/staticcheck/eslint clean.

2. RNG call-order drift — glibc-exact port, review checklist, harness counts draws per frame.
3. WebSocket head-of-line blocking at 10 Hz — original interpolation + adaptive jitter buffer; transport abstraction for WebTransport.

5. Save-format evolution — versioned + migrations + golden saves from day one.
6. Go GC pauses in the tick — preallocated arrays, `AllocsPerRun` tests, `SetMemoryLimit`, overrun metrics.
7. Legal — no data in repo, no derived fixtures committed, entitlement model, `LEGAL.md`.
8. Scope — `PARITY.md` is the contract; strict no-improvements rule; demo pak makes 6 of 9 phases testable without retail.
